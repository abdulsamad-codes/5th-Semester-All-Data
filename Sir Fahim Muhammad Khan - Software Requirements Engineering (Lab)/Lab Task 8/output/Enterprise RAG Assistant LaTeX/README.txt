Enterprise RAG Assistant SRS - LaTeX edition 1.1

Open main.tex in Overleaf or another LaTeX editor. Select pdfLaTeX and compile twice so the contents and page references update.

Local build:
  latexmk -pdf main.tex
Or:
  pdflatex main.tex
  pdflatex main.tex

All content is contained in main.tex. No external images or bibliography files are required. The document uses standard LaTeX packages listed in its preamble.

This edition shares the revised SRS content with the Word edition. Font metrics may produce a different page count. Open decisions in Section 6.3 remain pending approval.
