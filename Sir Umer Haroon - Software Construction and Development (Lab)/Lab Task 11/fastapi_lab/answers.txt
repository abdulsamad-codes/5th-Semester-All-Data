Task 3.2 - Validation error
Command: python client_validation.py

Status: 422
Error body:
{
  "detail": [
    {
      "type": "missing",
      "loc": [
        "body",
        "age"
      ],
      "msg": "Field required",
      "input": {
        "name": "Missing Age"
      }
    },
    {
      "type": "missing",
      "loc": [
        "body",
        "program"
      ],
      "msg": "Field required",
      "input": {
        "name": "Missing Age"
      }
    }
  ]
}

The missing fields are age and program. Each error identifies a missing value with
"type": "missing", and its "loc" entry points to the field in the request body:
["body", "age"] and ["body", "program"].

Task 4.1 - Interactive documentation
1. The interactive Swagger UI is at http://127.0.0.1:8000/docs.
2. The POST /students documentation shows a JSON request body with three required
   fields: name (string), age (integer), and program (string). It also describes
   the response for a successful creation and the validation error response.
3. FastAPI generates the documentation from the route declarations, type
   annotations, and the StudentCreate Pydantic model. These definitions provide
   the information used to build the OpenAPI schema; no separate documentation
   code was needed.
