You are a junior developer at a company called "BookWise Solutions." Your client is a local library that has three types of items: Books (which can be borrowed and returned), Magazines (which can be borrowed but not renewed), and DVDs (which can be borrowed and have a rental fee). The previous developer left behind a messy, poorly written program, and the client wants you to rebuild it properly. Your job is to create a complete working system using Object-Oriented Programming in any language of your choice. The program must have a simple menu where users can add items, borrow them, return them, and view all items. It must also save all item data to a file so that when the program is closed and reopened, the items are still there. Additionally, the client wants a "Late Fee Alert" feature: if any item has been borrowed for more than 14 days, the system should automatically mark it as overdue and display a warning. Your code must be clean, well-organized, and easy to run on any computer. Use private variables with proper getters and setters, handle invalid inputs without crashing, and make sure your program works perfectly when the instructor runs it. Submit your source code, a short README file with instructions on how to run it, and a few screenshots showing that all features work correctly.
