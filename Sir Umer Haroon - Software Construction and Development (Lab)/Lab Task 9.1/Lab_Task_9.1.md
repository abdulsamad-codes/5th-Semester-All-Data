## Task: Scrape faculty data with Beautiful Soup

You are required to scrape faculty data from any Pakistani university website of your choice using Beautiful Soup. The task involves the following steps:

### 1. Extract Faculty Information

- Scrape details such as faculty names, designations, departments, email addresses (if available), and contact information from the website.
- Save this information in a CSV file with appropriate headers (e.g., `Name`, `Designation`, `Department`, `Email`, `Contact`).

### 2. Download Faculty Images

- Scrape and download faculty profile pictures or any available images associated with the faculty members.
- Store these images in a folder named `faculty_images`.

### 3. University Information

Create a separate text file containing the following information:

- University Name
- URL of the faculty webpage you scraped.

### 4. Comment Section

In the comment section of your submission in Google Classroom (GCR), make sure to include the name of the university you covered. This will help ensure that each student is working on a different website.

## Submission

- Submit the CSV file with the faculty data.
- Submit the folder containing the faculty images.
- Submit the text file with the university name and the website link of the faculty page.
