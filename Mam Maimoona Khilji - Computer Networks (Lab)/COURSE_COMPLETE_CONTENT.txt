Quick Recap: Subnetting

Since subnetting was covered in the previous lab, we only need a short review.

What is subnetting?

Subnetting is the process of dividing a larger network into smaller networks called subnets.

For example:
                                     192.168.10.0/24
                                      ↓
                                         Subnetting
                           │
                ┌──────┬───────┬──────┐
                       ↓   ​       ↓   ​        ↓ ​​        ↓

                          /26   ​   ​       /26​        /26        /26



Each subnet has the same size when we divide a /24 into four /26 networks. Each /26 provides:

   ●​ 64 total addresses
   ●​ 62 usable host addresses

--- PAGE 4 ---
Key terms

    Term                         Meaning

 Subnet mask  Defines the network and host portions of an IP address

 Subnet     A smaller network created from a larger network

 Subnetting   The process of dividing a larger network into smaller networks





From Subnetting to VLSM

In traditional fixed-length subnetting, all subnets have the same size. For example:

                                     192.168.10.0/24

                                      ↓

                                         Subnetting
                           │
                ┌──────┬───────┬──────┐
                       ↓    ​      ↓    ​        ↓ ​​        ↓
                          /26   ​   ​       /26​        /26        /26

Each subnet provides 62 usable hosts. But imagine an organization has:


      Department       Hosts Required

 Data Science          50

 Administration        25

 Faculty              20

 Management          10


Giving every department 62 addresses would waste many addresses. This is where VLSM is
useful.

--- PAGE 5 ---
What is VLSM?

Variable Length Subnet Masking (VLSM) allows us to create subnets of different sizes within
the same network. Instead of:


      Department       Hosts Required   Prefix

 Data Science          50              /26

 Administration        25              /26

 Faculty              20              /26

 Management          10              /26


We can use:


      Department       Hosts Required   Prefix

 Data Science          50               /26

 Administration        25               /27

 Faculty              20               /27

 Management          10               /28



The prefix is selected according to the number of hosts required.

   VLSM = Different departments → Different subnet sizes




Fixed-Length Subnetting vs. VLSM

      Fixed-Length Subnetting              VLSM

 All subnets have the same size          Subnets can have different sizes

 Same prefix for all subnets              Different prefixes can be used

--- PAGE 6 ---
Easier to calculate                     Requires more planning

 Can waste addresses                 Uses addresses more efficiently

 Example: /26, /26, /26, /26            Example: /26, /27, /28


Suppose we need:

   ●​ Network A → 50 hosts
   ●​ Network B → 10 hosts

With fixed-length subnetting:

   ●​ A → /26 → 62 hosts
   ●​ B → /26 → 62 hosts

With VLSM:

   ●​ A → /26 → 62 hosts
   ●​ B → /28 → 14 hosts

The second approach uses the available address space more efficiently.



How VLSM Works

VLSM follows a simple process.

Step 1: List the host requirements

 Network      Hosts Required

 A        50

 B        25

 C        10

 D        5

--- PAGE 7 ---
Step 2: Arrange networks from largest to smallest


                                 Network A: 50
                                      ↓
                                 Network B: 25
                                      ↓
                                 Network C: 10
                                      ↓
                                  Network D: 5


Step 3: Choose the smallest subnet that can accommodate each requirement​


 Hosts Required  Prefix  Usable Hosts

 50               /26    62

 25               /27    30

 10               /28    14

 5                 /29    6


Always allocate the largest network first. This prevents address-space fragmentation and
makes the allocation easier to manage.




Choosing the Subnet Size

We already know the host formula from the previous lab, where n is the number of host bits.

                               Usable hosts = 2ⁿ − 2

For example, if we need 25 hosts:

   ●​  2⁴ − 2 = 14    Not enough
   ●​  2⁵ − 2 = 30   Enough

--- PAGE 8 ---
Therefore:

   ●​ 5 host bits
   ●​ 32 total addresses
   ●​ /27 prefix
   ●​ 30 usable hosts

Common VLSM choices

 Required Hosts  Total Addresses Needed     Prefix      Usable Hosts

 100            128                      /25          126

 50             64                        /26          62

 25             32                        /27          30

 20             32                        /27          30

 10             16                        /28          14

 5              8                         /29          6

Common VLSM Errors

Error 1: Choosing a subnet that is too small

50 hosts → /27

   ●​ Wrong because /27 provides only 30 usable hosts.
   ●​  Correct: 50 hosts → /26​


Error 2: Forgetting the network and broadcast addresses

   ●​ A /28 has 16 total addresses. 14 usable hosts, not 16 usable hosts.​


Error 3: Allocating networks in random order

   ●​ Always start with the largest requirement.​


Error 4: Overlapping subnets

--- PAGE 16 ---
For example:

   ●​ Network A → 192.168.50.0/26
   ●​ Network B → 192.168.50.32/27

These overlap. Make sure that each subnet begins after the previous subnet's address space ends.​


Error 5: Wrong default gateway

The gateway should normally be a usable host address within that subnet, commonly the first
usable address in the lab design.
